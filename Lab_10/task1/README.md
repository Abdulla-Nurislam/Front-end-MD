## Project Overview
This project implements a `TodoList` component with comprehensive unit testing using Jest and React Testing Library.

## Features
- Add tasks via button or Enter key.
- Toggle task completion.
- Delete tasks.
- Real-time task counter.

## Testing Setup
- **Jest:** Experimental VM modules enabled for ESM support.
- **ts-jest:** Configured for TypeScript support in tests.
- **Testing Library:** RTL and user-event for realistic interaction testing.

## Commands
- `npm test`: Run all tests.
- `npm test -- --coverage`: Run tests and generate coverage report.
