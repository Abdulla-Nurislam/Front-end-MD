2. Конкретные промты\
\
Промт 1: «В чем разница между модульным (unit) и интеграционным тестированием в React, и почему для этого лучше использовать React Testing Library (RTL)?»\
\
Что получил?\
Объяснение о том, что модульное тестирование проверяет компоненты в изоляции, а интеграционное — их взаимодействие. RTL предпочтительнее, так как она тестирует поведение пользователя (DOM), а не внутреннюю реализацию (state/props), что делает тесты более устойчивыми к рефакторингу.\
\
Промт 2:\
«Как настроить Jest для работы с проектом на Vite и TypeScript, учитывая требования к использованию ESM (ECMAScript Modules)?»\
\
Что получил?\
Пошаговую инструкцию по установке `ts-jest`, настройке `jest.config.js` с флагом `useESM: true` и необходимости включения `NODE_OPTIONS=--experimental-vm-modules` для корректной обработки модулей в среде Jest.\
\
Промт 3:\
«Что такое CI/CD, и как настроить GitHub Actions для автоматического запуска тестов перед деплоем на Vercel?»\
\
Что вы получили?\
Объяснение концепции CI/CD (интеграция и доставка). Пример файла workflow (`ci.yml`), который выполняет два этапа: `test` (прогон Jest и сборка coverage) и `build` (сборка проекта), гарантируя, что на деплой попадает только рабочий код.
