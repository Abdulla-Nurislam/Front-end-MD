2. Конкретные промты\
\
Промт 1: «Как настроить навигацию в React Native с помощью Expo и React Navigation, и в чем разница между Stack и Tab Navigator?»\
\
Что получил?\
Объяснение принципов работы `@react-navigation/native-stack`, пошаговую инструкцию по установке `NavigationContainer` и `Stack.Navigator`, а также примеры передачи параметров (route.params) между экранами.\
\
Промт 2:\
«Как правильно использовать FlatList для рендеринга списка товаров и в чем его преимущество перед ScrollView?»\
\
Что получил?\
Пояснение, что FlatList рендерит только видимые элементы, что значительно улучшает производительность для больших списков. Получил пример правильного использования `keyExtractor`, `renderItem` и настройку `Pull-to-refresh` (RefreshControl).\
\
Промт 3:\
«Как писать платформо-зависимый код (iOS vs Android) в React Native для изменения стилей компонентов (теней)?»\
\
Что вы получили?\
Пример использования `Platform.OS` и `Platform.select()` для задания `shadowColor` на iOS и `elevation` на Android, чтобы интерфейс выглядел нативным на обеих платформах.
